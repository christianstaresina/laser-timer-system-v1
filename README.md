\# Laser Timer System V1



A portable laser timer system consisting of a start gate and an end gate. Upon crossing through the start gate, a timer begins counting until the end gate is crossed. Once the end gate is crossed, the total elapsed time from start to finish is displayed on the end gate's built-in display.



An example application of this system is a sprinter using it for speed training. The start and end gates can be placed a measured distance apart to accurately track sprint time progress. A sprinter can also input the distance between the gates and display the average speed in miles per hour achieved during the elapsed time.
